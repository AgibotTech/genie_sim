# Dream example cases

These 20 packs each register two catalog entries: the example ID for replaying its recorded actions, and `pi05-<example ID>` for a fresh external-policy closed loop. They contain initial observations and states, normalized actions, and no recorded world-model outputs.

The files in these 20 example bundles are licensed under [MPL 2.0](../LICENSE).

Generated session replays are runtime outputs and are not part of this example set.
