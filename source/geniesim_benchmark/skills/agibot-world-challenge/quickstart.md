# Challenge quickstart

1. Prepare [training data](challenge-download-datasets/SKILL.md) and the [baseline model](challenge-baseline-model/SKILL.md) if needed.
2. [Log in](challenge-login/SKILL.md) and save the token.
3. [Check quota and submit a job](challenge-submit-job/SKILL.md).
4. [Launch the inference agent](challenge-run-agent/SKILL.md) with the returned job credentials.
5. [Poll status and scores](challenge-poll-result/SKILL.md), then inspect the [ranking](challenge-ranking/SKILL.md).

The [skills README](README.md) defines shared state and shell persistence.
